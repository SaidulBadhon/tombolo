Set Up Enhanced Mode

Unlock the full experience

Standard mode uses only what a normal Android app is allowed to do. Enhanced mode adds a small helper that runs with Android’s developer (“shell”) permissions — the same technique scrcpy uses. Nothing is rooted and you can turn it off at any time.
