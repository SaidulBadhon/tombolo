# S13 — app-shim viewer (spike, throwaway)

Can each Android app get its **own Dock icon, ⌘-Tab entry and Spotlight entry** by generating a small local
`.app` "shim" per app (the Chrome PWA app-shim pattern), where the shim owns an `NSWindow` and shows frames the
main app sends it — and does that survive host restarts and host updates without paid signing?

Result write-up: [`docs/spikes/s13-app-shim.md`](../../docs/spikes/s13-app-shim.md). This code is throwaway
(see [`spikes/README.md`](../README.md)); production code is rewritten in `apple/` if Phase 4 builds shims.

## IPC design in one paragraph

The host claims a **dynamic bootstrap name** (`io.github.saidulbadhon.Tombolo.spike-s13.ipc`) with
`bootstrap_check_in` — no launchd plist, no LaunchAgent, nothing persistent; launchd drops the name when the host's
receive right dies. Shims `bootstrap_look_up` it and talk **raw Mach messages**. Frames are **IOSurfaces sent as
Mach port rights** (`IOSurfaceCreateMachPort` → `IOSurfaceLookupFromMachPort`): a ring of three surfaces is sent once
per session, then each frame is a 20-byte message naming the slot; the shim sets the surface as its layer's contents
(zero-copy, WindowServer composites it) and acks, which frees the previous slot. Dead-name notifications detect
either side dying; `notify(3)` tells waiting shims the host is back. The host pins each shim it generated by
**ad-hoc cdhash** (`identifier "…" and cdhash H"…"` checked against the Mach audit token). This is how Chromium's
app shims rendezvous (`com.google.Chrome.apps.<hash>` shows up as a dynamic name in `launchctl print gui/$UID`).
Why not XPC: an XPC Mach-service *listener* only works inside a launchd-managed job (probe: "Connection invalid"),
so XPC would need a LaunchAgent broker — the fallback, verified to work, but with launchd state to manage.

## Requirements

Apple silicon Mac, macOS 14+ (only 27.0.1 tested), Swift 6 **Command Line Tools** (no Xcode), a logged-in GUI
session. No `sudo`, no paid signing, no network. The experiments open real windows for a few seconds at a time and
take window screenshots with `screencapture -l` (needs Screen Recording for the terminal; it is checked with
`CGPreflightScreenCaptureAccess`, which never prompts — without it the capture lines just fail).

## Build and run

```sh
cd spikes/s13-app-shim
scripts/build.sh            # → out/Tombolo Host.app (version 1); `scripts/build.sh 2` simulates an update
open "out/Tombolo Host.app" # generates ~/Applications/Tombolo Apps/{Chat,Maps}.app and launches them
```

Host options (pass after `open … --args`, or run `out/Tombolo Host.app/Contents/MacOS/TomboloHost` directly):
`--apps pkg:Name,…` · `--fps 60` · `--size 720x1560` · `--mode ring|perframe` · `--duration S` · `--warmup S` ·
`--no-launch` · `--generate-only` · `--force-regenerate` · `--no-update-shims` · `--selftest-events` ·
`--stats out.json`. Quit with ⌘Q or `kill -TERM` (graceful: shims show "host quit"); `kill -KILL` simulates a crash.

Logs (one line per event, prefixed with `CLOCK_UPTIME_RAW` ms so files from different processes merge):
`~/Library/Application Support/Tombolo-spike-s13/logs/{host,shim-<package>}.log`. Generated-shim records (cdhash
pins): `…/Tombolo-spike-s13/shims.json`.

## Experiments

```sh
scripts/experiments.sh measure      # 4 latency/CPU runs (20 s each): ring vs per-frame, 1080x2400, 4 shims
scripts/experiments.sh restart      # host graceful quit / crash / shim crash / second host instance
scripts/experiments.sh coldstart    # launch a shim while the host is down → it starts the host
scripts/experiments.sh integration  # Spotlight indexing, lsappinfo, windows, signatures, xattrs, spctl
scripts/experiments.sh security     # impostor shims rejected; name squatting while the host is down
scripts/experiments.sh quarantine   # quarantine on the host's template does not reach generated shims
scripts/experiments.sh update       # host v1 → v2 (new cdhash): shims restart, regenerate, reconnect; v3 compat
scripts/experiments.sh all          # all of the above, then the TCC / Gatekeeper log sweep
scripts/experiments.sh logs "2026-10-26 01:20:00"   # TCC + syspolicyd log lines naming our code since then
```

`update` rebuilds the host (versions 1 → 2 → 3) and restores version 1 at the end.

## Cleanup

```sh
scripts/cleanup.sh
```

Stops every host/shim process, unregisters every shim and host path from LaunchServices (`lsregister -u`), deletes
the shims in `~/Applications/Tombolo Apps` (only bundles marked `TomboloSpike = s13`), the built
`out/Tombolo Host.app` (Spotlight indexes it even inside the repo) and the state directory
(logs are archived to `out/logs-<timestamp>/` first), removes `/tmp` leftovers, then verifies: no directory, no
process, no launchd entry, no LaunchServices record, and Spotlight returns nothing for `io.github.saidulbadhon.Tombolo.*`.
The spike registers **no launchd jobs**; the script also boots out the probe's temporary LaunchAgent in case a probe
run was interrupted. Recreate everything with `scripts/build.sh && open "out/Tombolo Host.app"`.
