# proto/ — protocol schemas

> **No schemas here yet.** This directory is a placeholder from Phase 0 (task P0-01). The prose specification
> is [`docs/protocol.md`](../docs/protocol.md) (draft).

**Purpose:** the Protobuf schemas for the Tombolo protocol — the single source of truth that both apps and
[`tombolo-core`](../core/README.md) generate code from — plus conformance data in `testdata/`: golden
transcripts and the pairing test vectors from the Phase 0 security design (task P0-03 writes
`testdata/pairing/`, regenerated by a script in `tools/pairing-vectors/`).

**Future owner:** the Android + core track (Dev B); changes are reviewed by the Mac track (Dev A) — see
[implementation plan §2](../docs/implementation-plan.md#2-resource-loaded-estimate-and-schedule-two-developers).
